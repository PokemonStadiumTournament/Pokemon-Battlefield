# Pokemon Battlefield

Our application, Pokemon Battlefield is for kids and adults who also like Pokemon. It allows users to simulate battles in the Pokemon style.
[Demo Video](https://youtu.be/CVh8e2aEDlo?si=Ghsgp2dRInVWW0p4)

## Features:

- Users can select a Pokemon out of 9 distinct Pokemons.
- Users can BATTLE against a computer.
- Pokemon moves will be randomized from a pool of moves containing the hundreds of moves each pokemon can learn.

#

**Technologies Used:** React, JavaScript, PokeAPI, and CSS
